## 🎯 What is this?
This is a completely **frontend-only** web project built for fun. It simulates a hacker/cyberpunk dashboard vibe with interactive elements, terminal-style UI, and smooth animations. There is no backend, no database, and absolutely no real hacking involved.

## 🧩 Features
- **Hacker Terminal Aesthetic** — Black & Red cyberpunk theme with glitch and typewriter effects.
- **Interactive Terminal** — Type commands like `help`, `about`, `contact`, and `hack` to see fun responses.
- **Skills Arsenal** — A grid of cybersecurity domains with cool hover effects.
- **The Crew** — Team profiles with scanline hover animations.
- **Fun Zone** — CTF countdown timers and mission cards.
- **Secure Contact Channel** — Email, phone, and Instagram with copy-to-clipboard functionality.
- **Custom Cursor & Matrix Rain** — Pure vibe, pure frontend.

## 🛠️ Tech Stack
- **HTML5** — Structure
- **CSS3** — Styling, animations, glitch effects, scanlines
- **Vanilla JavaScript** — Interactivity, typewriter effect, terminal logic, countdown timer, clipboard actions
